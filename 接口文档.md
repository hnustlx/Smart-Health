# 智能健康助手接口文档

## 1. API Overview

### Base URL

```text
http://localhost:8080/api/v1
```

### Content Type

```text
application/json
```

### Authentication

除注册、登录接口外，其余接口均需携带 JWT Token。

```text
Authorization: Bearer <token>
```

### Standard Response

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

### Common Error Responses

| Code | Message | Description |
| --- | --- | --- |
| 400 | 参数错误 | 请求参数缺失或格式错误 |
| 401 | 未登录或 Token 无效 | 未携带 Token 或 Token 无效 |
| 403 | 无权限访问 | 当前角色无权限 |
| 404 | 数据不存在 | 查询或操作的数据不存在 |
| 409 | 数据冲突 | 用户名重复等冲突 |
| 429 | 请求过于频繁 | 触发限流，请稍后重试 |
| 500 | 系统异常 | 后端服务异常 |
| 600 | AI 服务调用失败 | AI 服务调用失败 |
| 601 | Chroma 检索失败 | Chroma 向量检索失败 |

### 8.2 Save AI Config

**Endpoint**

```text
POST /ai-config
```

**Auth**

```text
USER / VIP / ADMIN
```

**Request Headers**

| Name | Required | Description |
| --- | --- | --- |
| Authorization | Yes | Bearer Token |
| Content-Type | Yes | application/json |

**Request Body**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| provider | string | Yes | DEFAULT / CUSTOM / LOCAL |
| apiKey | string | No | 自定义 API Key，provider=CUSTOM 时必填 |
| apiUrl | string | No | 自定义 API 地址，默认 https://api.deepseek.com/v1/chat/completions |
| model | string | No | 模型名称，provider=CUSTOM 时可选，provider=LOCAL 时必填 |

**注意：**
- `CUSTOM`：使用用户自己的 API Key 调用 DeepSeek
- `LOCAL`：使用本地 Ollama 模型（需 VIP 身份）
- `DEFAULT`：恢复为服务器默认 DeepSeek Key

**Example**

```json
{
  "provider": "CUSTOM",
  "apiKey": "sk-your-custom-key",
  "model": "deepseek-chat"
```
